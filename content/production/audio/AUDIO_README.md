# Watoto — Audio Production Guide

Four files make up the audio package (all regenerated by `build_audio_manifest.py`):

- `audio_manifest.csv` — the master voiceover (VO) script: one row per spoken line per language.
- `audio_sfx_manifest.csv` — declared sound-design assets (effects, music beds, spoken cues).
- `audio_manifest.json` — counts, per-stage/field breakdown, and duration estimate.
- `AUDIO_README.md` — this guide.

## File naming (important)

Every VO clip's path is derived from the i18n key the app already uses for captions:

    audio/<lang>/<i18n-key>.mp3
    e.g.  audio/sw/s09.reading.lesson.01.steps.0.narration.mp3

So a single dotted key resolves both the on-screen caption text and its audio, in any locale. The app should load `audio/<userLang>/<key>.mp3` and fall back to `audio/en/<key>.mp3` if a localized clip is missing — the same English-fallback rule the text bundles use. Because paths are deterministic, re-recording after an edit means re-rendering only the changed keys (diff the `i18n_key` column between manifest versions).

## What gets voiced

The VO script covers child-facing read-aloud only: lesson narration and feedback, quiz prompt / option / correct / retry, and story narration. Titles (565) and parent notes (122) are excluded by default — titles are UI labels and parent notes are adult-facing. Add them to VO only if the app announces them.

Totals: 2,661 unique lines per language → 7,983 clips across en/fr/sw. Rough spoken length at 130 wpm plus padding is about 157 min (en), 186 min (fr), and 142 min (sw) — roughly eight hours of finished audio in total. Treat these as planning estimates, not session bookings; the `est_seconds`/`words` columns let you re-roll the math at a different pace.

## Voice direction

Each row carries a `voice_direction` and an `age_tone`. In short: narration is a warm, unhurried guide that invites the child to act; feedback is brief and upbeat; correct-answer lines give gentle praise without going over the top; retry lines stay supportive and never sound disappointed; story narration is expressive and varies pace. Tone shifts by age band — stages 1–2 are soft, slow, and sing-song; 3–4 playful and simple; 5–6 a little more pace; 7–10 conversational and respectful.

## Locale review before recording FR/SW

The `review_for_locale` column flags 284 French/Swahili lines whose text is currently identical to the English. Most are intentional and can be voiced as written: numerals (`92`, `0.6`), Python tokens (`print(...)`, `for i in range(4)`), and proper nouns (London, Africa, Nile). But this column also surfaces the language-specific teaching content that must be **re-scripted per language before recording**, because the lesson only works in English:

- Phonics and word study — letter sounds, CVC blending, digraphs (sh/ch), silent-e, vowel teams, sight words, word families, compound words, prefixes un-/re-, contractions.
- Plurals and verb-tense conjugation — walk/walked/will walk, box/boxes.
- Quotation and dialogue punctuation — French uses « » with different comma placement (e.g. `s09.writing.lesson.03`, `s09.writing.quiz.03`, `s10.writing.lesson.04`).
- Idioms — kept in English on purpose (`s10.reading.lesson.02`); each language needs its own idioms.

Everything else — math, science, social studies, coding, and the comprehension/composition skills (theme, inference, cause/effect, summarizing, essay structure) — is already fully localized and ready to record.

Two smaller content notes for narration accuracy: the four-seasons material is temperate-zone (the Swahili season names are approximations; East Africa runs on wet/dry seasons), and a couple of benign duplicate lesson titles exist by design (Stage 6 "Tens and Ones", Stage 8 "Food Chains").

## Sound design

`audio_sfx_manifest.csv` lists 87 declared assets: 24 effects and 8 music beds that are language-neutral (source or record once), and 55 spoken cues (e.g. "mama", "dada", "peekaboo!", narrator beds) that need localizing in all three languages. The kind/localize split is set by a keyword heuristic, so the audio lead should eyeball the `kind` column and reclassify anything borderline.

## Suggested workflow

1. Lock scripts: run the re-script pass on the `review_for_locale` lines above, then regenerate the manifest so the flags clear.
2. Produce per locale. TTS is consistent and cheap and works well for quiz options, prompts, and feedback; human voice adds warmth for the youngest stages and for stories — a hybrid is reasonable.
3. Export to the exact `audio_path` values. Since each row's `text` is the caption source too, captions and audio stay in sync from one file.
4. Re-run `build_audio_manifest.py` after any content or translation change; only changed keys need new audio.
